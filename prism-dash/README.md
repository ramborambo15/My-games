# Prism Dash

An original fast 3D browser platformer inspired by classic momentum arcade games.

## Run Locally

This game uses JavaScript modules, so run it with a small local server.

```powershell
cd C:\Users\jhale\Documents\Codex\2026-04-27\hello\prism-dash
node server.js
```

Open:

```text
http://127.0.0.1:8090/
```

## Controls

- Left / Right or A / D: accelerate and brake
- Space: jump
- Down / S: roll attack
- R: restart after game over

## Upload

For the arcade site, upload the `website-upload` folder contents from the parent project. Prism Dash lives at:

```text
website-upload/prism-dash/
```
