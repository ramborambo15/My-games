# Neon Drift: Skyfall

A Three.js browser game: futuristic hover-bike survival racing through a neon sky city.

## Run Locally

This game uses JavaScript modules, so run it through a local server.

From this folder:

```powershell
node server.js
```

Then open:

```text
http://127.0.0.1:8080/
```

If `node` is not available on your computer, you can also upload the folder to GitHub Pages and play it from the live site.

## Controls

- `A` / `D` or arrow keys: change lanes
- `Space`: jump
- `Shift`: boost
- `Escape`: pause
- `R`: restart after game over

## Website Upload

For the existing arcade site, upload the full `website-upload` folder contents from the parent project. The game lives at:

```text

```
