# Rambo Arcade Game Boy Player

This separate player application (gameboy-player.html, player.js, player.css) is licensed under GPL-3.0-or-later, together with its WasmBoy dependency. This does not change the licensing of the other arcade games. See LICENSE.txt.

WasmBoy 0.7.1 is by Aaron Turner and contributors. The runtime bundle is the npm-published `dist/wasmboy.wasm.esm.js`, renamed to `wasmboy.js`, with the save-restore fix described below. Corresponding patched source and upstream build configuration are provided in `wasmboy-source.zip`; upstream commit: `8e96bcb70969d943b1ffc4028b169c835098ce04`. Original source: https://github.com/torch2424/wasmboy. The runtime bundle includes its workers and WebAssembly core, so no CDN is needed. The emulator bundle and source archive contain no game ROMs or proprietary boot ROMs.

Rambo patches (11 October 2026): all four audio-channel `loadState()` methods used the current `cycleCounter` as the save-state slot index, instead of each channel's fixed `saveStateSlot`. Repeated restores could read the wrong sound state or trap with an out-of-bounds memory access. The four reads now use slots 7, 8, 9, and 10. The graphics scanline register likewise restores from its fixed slot 1. Channel 1 now restores its sweep counter as i32 and its sweep shadow frequency as u16, matching their saved widths. The fixes preserve complete internal state across repeated restores in the included games. Corresponding source changes and the reproducible patch script are included in the source archive. The bundled WASM was patched with equivalent constant operands and load widths, preserving byte offsets; the rest of the runtime is unchanged. The original core SHA-256 is `f2d6a734ce5c3e752c98173b194128fd72f688d0cff226a3e5f61d9930de83a8`, and the patched core is `4274288a44a9dee219628c4f0936442dfb5b13a31bf5d0ef7bb49196b8c8289b`.

The player supports raw .gb and .gbc cartridges up to 4 MB, using ROM, MBC1, MBC2, MBC3, and MBC5 cartridge types. Game Boy Advance, ZIP files, and special cartridges such as the Game Boy Camera are unsupported. ROM compatibility varies by game.

Ready-to-play games can be opened with `gameboy-player.html?game=<id>` or the cartridge buttons. Valid ids are `pokemon-crystal`, `pong`, `minesweep`, and `acattag`. Only these fixed catalogue entries can be fetched; arbitrary URL/query values are ignored. Downloads are validated as cartridges and have a 30-second timeout. Loading pauses an existing game first, and a failed download lets the existing game continue.

Pokémon Crystal uses the same-origin asset `games/pokemon-crystal-fdcc3c8c.gbc`, SHA-256 `fdcc3c8c43813cf8731fc037d2a6d191bac75439c34b24ba1c27526e6acdc8a2`. The site owner supplied this file and confirmed permission to redistribute it. That game is separate from the GPL player/emulator and is not covered by their license.

Pong and Minesweep by Maximilien Dagois (CC0), and ACATTAG by Andrea Stewart (MIT), use same-origin game files copied byte-for-byte from the authors' official GitHub ROMs at immutable commits. They are fetched with no credentials or custom headers. The hash-named files are `games/pong-d9a88547.gb`, `games/minesweep-098427b0.gb`, and `games/acattag-7167d67a.gb`. ACATTAG is labelled as a prototype because its author acknowledges synthesis glitches. Credits, source revisions, full ROM hashes, and licence copies are in `games/CREDITS.txt` and `games/licenses/`.

Files selected with Load game are read in the browser and never uploaded or stored in the repository. Rambo's IndexedDB store, `rambo-pocket-saves`, uses the SHA-256 digest of the entire ROM to distinguish saves. There is one autosave and one independent quick save per game. Autosave runs every 20 seconds while playing and when pausing, switching games, or hiding the page. Open the same ROM to resume the most recent state. Identical local and included copies share saves, including progress saved immediately before reopening the game. Personal files must be reselected after refreshing; the included game can be opened directly again. Clearing browser data removes saves; export a backup first. Private browsing may make saves temporary or unavailable.

Export/import uses a versioned Rambo JSON snapshot (.rambo-save), containing no ROM. Imports validate the ROM hash, emulator version, and exact memory dimensions. These snapshots aren't interchangeable with another emulator's .sav battery files.

Keyboard: arrows/WASD = move, X = A, Z = B, Enter = Start, Shift = Select, P = pause. Touch controls support simultaneous pointers, diagonals, sliding on the D-pad, and release on cancellation/focus loss. Fullscreen is optional and subject to browser support.
